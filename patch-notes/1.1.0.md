# TapCatForever 1.1.0

- Targets World of Warcraft: Forever (interface 16001) and its modern addon API.
- Uses modern APIs only (C_AddOns, class icon atlases, missing-icon fallback).
- Adds a page under Options > AddOns.
- Never reads game values that may be "secret" in combat; the cast fallback uses whichever spellcast event the client provides.
